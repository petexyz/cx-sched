# CX schedule 2026-27

International cyclocross calendar (World Cup, Superprestige, X²O Trofee, HG Cross, Euros, Worlds, national championships, US UCI races) with where to watch in the US, start times in Eastern, links, and a map.

Live page: https://petexyz.github.io/cx-sched/

Open `index.html` locally to run it. No build step; the map needs an internet connection.

- `data.js`: all the data
- `time.js`: converts venue-local start times to US Eastern
